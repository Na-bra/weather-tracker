# weather-tracker
A simple weather app that provides real-time weather updates, temperature, humidity, and forecasts for any location. Users can quickly check current conditions and upcoming weather with a clean, easy-to-use interface.

## Tech stack
- Node.js + Express backend
- React frontend
- Open-Meteo API (geocoding + forecast)

## Run locally
```bash
npm install
npm start
```
Then open `http://localhost:3000`.

## Usage
1. Enter a city name.
2. Click **Get Weather**.
3. View current temperature, humidity, and 3-day forecast.
